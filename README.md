## 怎么用

1. 把 `amazon-telly-ad-funnel-diagnosis/` 放到 skills 目录（如 `.claude/skills/`）。
2. 说「诊断一下 XX 款的广告」「这个款广告该不该调」即可触发。
3. 首次使用需提供：款号 / 站点 / 时间窗口 / 货值 + 头程 / 类目基准（点击率、转化率、退货率标准）；缺的部分对应块写「数据缺失，本块跳过」。
4. 复刻 HTML 时：先读 SKILL.md 第 4、6 节定内容与版式，再读附录 A 拿设计 token 和组件清单，最后打开 `examples/` 里的样板报告逐块对照。

## 核心口径（速查）

- 真实保本 ACOS = 留下来的毛利 ÷ 销售额（近 90 天实际入账，不是名义保本）。
- 三道闸门：点击率、转化率、退货率，指数 = 我 ÷ 基准，刻度 0.7 / 1 / 1.3；任一被拦截 → 广告侧只做减法。
- 零单点击阈值：初筛 1.5 ÷ CVR，终判 2.3 ÷ CVR。
- 报告 = 首页 + 5 章共 31 块，输出单文件 HTML；全程只读，不改任何广告。

## 关于示例报告

- 用途：给复刻方一个「成品长什么样」的参照，覆盖全部 31 块、所有组件与判定标签。
- 数据：**不是任何真实账户的数据**。账户名、ASIN、搜索词、日期、金额、百分比均已替换为虚构值（在原始报告基础上整体变换生成），点击 / 订单等计数量级保留。
- 因此示例里的数值只保证「量级与判定方向合理」，不保证严格勾稽（例如成交价 × 保本线不一定正好等于零单花费阈值）。要精确勾稽，请用真实报表重跑。
